# Non-Linear & Robust Control - Exercise Report

## Overview
This repository contains MATLAB implementations and theoretical analyses for various control systems, including Riccati equations, pendulum regulation, non-linear equations, mass-spring-damper systems, adaptive control, and robotic systems (2-link planar robot and unicycle). The exercises cover both linear and non-linear dynamics, stability analysis, and trajectory tracking.

## Contents
1. **Algebraic Riccati Equation (ARE) Solution**  
   - Numerical solution using MATLAB's `ode45`.  
   - Implementation of Differential Riccati Equation (DRE) and ARE.  

2. **Pendulum Regulation with Partial Information**  
   - Linearized cart-pendulum system control.  
   - Full and partial information feedback strategies.  

3. **Non-Linear Equations Analysis**  
   - Solutions for \(\dot{x} = x^2\), \(\dot{x} = -x^3\), \(\dot{x} = x^3\).  
   - Existence, uniqueness, and Lipschitz conditions.  

4. **Tunnel Diode Circuit Equilibrium Analysis**  
   - Numerical solution for equilibrium points.  
   - Jacobian and eigenvalue analysis for stability.  

5. **Mass-Spring-Damper Systems**  
   - Linear and non-linear cases (cubic stiffness/damping).  
   - Lyapunov stability and phase plots.  

6. **Adaptive Control of Scalar Systems**  
   - Trajectory tracking with known/unknown parameters.  
   - Lyapunov-based adaptive laws.  

7. **2-Link Planar Robot Control**  
   - Joint and operational space regulation.  
   - Trajectory tracking and adaptive control.  

8. **Unicycle Robot Trajectory Tracking**  
   - Feedback linearization for position control.
